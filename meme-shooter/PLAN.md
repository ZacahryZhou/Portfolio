# Meme Shooter 开发方案（给 Claude Code）

## 0. 一句话
网页版横版卡关射击小游戏。主角、小兵、Boss 都用真实照片当脸，搞笑风格，轻松难度。纯前端，双击 `index.html` 就能玩。

## 1. 技术约束
- 纯 HTML + CSS + JavaScript，用 Canvas 2D 渲染，不用框架，不用打包工具。
- 文件结构：
  ```
  meme-shooter/
    index.html        # 页面和 canvas
    style.css         # 外壳样式（居中、黑底、字体）
    game.js           # 游戏主循环和所有逻辑（先放一个文件，超过 800 行再拆）
    assets/
      player.png      # 主角头像，150x150 圆形透明底
      minion.png      # 小兵头像，120x120 圆形透明底
      boss.png        # Boss 全身像，190x357 透明底
    README.md
  ```
- 画布固定逻辑分辨率 960x540，用 CSS 等比缩放适配窗口。
- 主循环用 `requestAnimationFrame`，物理和计时用 delta time（秒），不依赖帧率。
- 音效全部用 Web Audio API 合成，不引入音频文件。
- 语音台词用 `speechSynthesis`，语言 `zh-CN`；浏览器不支持时只显示字幕。
- 最高分存 `localStorage`，读写都要 try/catch。
- 音频和语音必须在第一次用户点击或按键之后才启动（浏览器限制）。

|---|---|---|

## 3. 游戏设计

### 3.1 主角
- 外观：`player.png` 当脑袋，下面画简单身体（矩形躯干 + 两条腿，走路时腿摆动）。
- 生命：3 颗心。被击中后无敌 1.5 秒，闪烁。
- 移动速度 260 px/s，跳跃高度约 140 px，重力 1800 px/s²。
- 射击：子弹是一个小笑脸或飞出的 `{`}` 符号，速度 700 px/s，射击间隔 0.25 秒。

### 3.2 小兵
- 外观：`minion.png` 当脑袋，身体画成一只 bug（六条腿，会爬）。
- 类型：
  1. **爬行 Bug**：沿地面朝主角走，1 滴血，速度 90 px/s。
  2. **飞行 Bug**：在空中正弦波飘动，2 滴血，每 2 秒掉一个"报错弹"。
  3. **跳跃 Bug**：每 1.5 秒跳一次，1 滴血。
- 被打死：爆成几个小方块粒子，播放"噗"音效，加分 100。

### 3.3 Boss「Deadline」
- 外观：`boss.png` 全身像，站在场景右侧，位置固定，轻微上下浮动。
- 生命 60，屏幕上方显示血条，名字「Deadline」。
- 三个阶段（按血量切换）：
  1. 血量 100%–60%：每 1.8 秒发射 5 发扇形「作业」纸片弹（纸片矩形，旋转飞出）。
  2. 血量 60%–30%：加上冲撞，每 6 秒冲向左侧一次，先有 0.8 秒预警红线，玩家可跳过。
  3. 血量 30%–0%：每 4 秒召唤 3 只飞行 Bug，纸片弹加到 7 发。
- 被击中时 `boss.png` 闪白 0.08 秒。
- 击败：慢动作 1.5 秒，全屏爆炸粒子，进入通关结算。

### 3.4 关卡（第一版只做第 1 关）
- 第 1 关「Bug 森林」：横向滚动长度 4800 px，约 60 秒。
  - 0–1200 px：只有爬行 Bug，教学。
  - 1200–3000 px：混入跳跃 Bug 和飞行 Bug。
  - 3000–4800 px：出现道具箱，然后进入 Boss 房间（锁定屏幕，不再滚动）。
- 背景：三层视差滚动（远处的山、中景的树、地面），全部用 Canvas 画渐变和几何形状，不用图片。
- 关卡数据写成一个对象数组 `LEVELS`，每个元素描述出怪点（x 位置、类型），第 2、3 关以后只加数据。

### 3.5 道具
道具从被打死的小兵身上有 15% 概率掉落，或藏在道具箱里（打碎）。拾取后持续 10 秒（护盾和大招除外）。

| 道具 | 外观 | 效果 |
|---|---|---|
| 咖啡 | 棕色杯子 | 移动速度 +30%，射击间隔减半 |
| 双发 | 双箭头图标 | 一次射两发，上下错开 |
| 护盾 | 蓝色泡泡 | 抵挡 1 次伤害，不限时 |
| Ctrl+Z | 键盘按键图标 | 存 1 个大招，按 K 清除屏幕上所有小兵和敌方子弹 |
| 爱心 | 红心 | 回 1 颗心，最多 3 颗 |

### 3.6 难度（轻松爆笑）
- 敌方子弹速度慢，判定框比外观小 20%。
- 玩家判定框只取脑袋中心的小圆，比图片小一圈，擦边不算中。
- 每次死亡后，下一次尝试 Boss 血量减 10%，最低减到 50%（防止卡关挫败）。
- 道具掉落率 15%，主角没有血时下一个小兵必掉爱心。

## 4. 画面流程（状态机）
`TITLE → PLAYING → (PAUSED) → BOSS → WIN 或 GAMEOVER → TITLE`

### 4.1 标题页
- 大标题：**游戏名**（待定，默认「Zachary 大战 Deadline」）。
- 主角头像大图在中间轻轻上下浮动。
- 提示：「按任意键开始」，下方显示最高分。
- 点击后启动音频，语音说开场白。

### 4.2 结算页（重点，要搞笑）
**失败页 GAMEOVER**
- 屏幕中央放大显示 `player.png`，加灰色滤镜，头上飘几个 💀。
- 大字：「你被 Deadline 抓住了」。
- 台词随机一句，字幕出现同时语音朗读（见第 5 节）。
- 显示：得分、击杀数、最高分。
- 按钮：「再来一次」（按 R）。

**通关页 WIN**
- 左边放大显示 `player.png`，戴一个用 Canvas 画的小皇冠，周围喷彩带粒子。
- 右边把 `boss.png` 画成倒地状态（旋转 90°，头上转圈圈）。
- 大字：「Deadline 被你搞定了」。
- 台词随机一句，字幕加语音。
- 显示：得分、用时、受伤次数，如果破纪录显示「新纪录」。

## 5. 台词和语音
所有台词放在 `LINES` 对象里，方便后续改。语音用 `SpeechSynthesisUtterance`，`lang = 'zh-CN'`，`rate = 1.1`，`pitch` 可按角色调整：主角 1.2，小兵 1.6，Boss 0.7。

```js
const LINES = {
  start:   ["今天的作业，我一个字都不会交！", "来吧，Deadline，我准备好了。"],
  hit:     ["哎哟！", "别打脸！", "我的脸！"],
  kill:    ["Bug 已修复。", "下一个！", "代码审查通过。"],
  powerup: ["续命成功！", "咖啡续一波。"],
  bossIntro: ["你的作业呢？", "交了吗？"],
  bossHit: ["你再写啊！", "时间不多了！"],
  gameover: ["Deadline 又赢了。", "明天再战，今晚先睡。", "这个 Bug 我下次一定修。"],
  win:     ["提交成功，满分！", "Deadline，你也有今天。", "我才是时间的主人。"]
};
```
这些是初稿，你可以直接改成你和朋友之间的梗。

## 6. 音效（Web Audio 合成）
| 事件 | 合成方式 |
|---|---|
| 射击 | 方波 880→440 Hz，0.08 秒 |
| 击中敌人 | 噪声短脉冲 0.05 秒 |
| 小兵死亡 | 三角波 300→80 Hz，0.15 秒 |
| 拾取道具 | 方波 523、659、784 Hz 依次短音 |
| 玩家受伤 | 锯齿波 200→60 Hz，0.3 秒 |
| Boss 登场 | 低频三角波 60 Hz，0.8 秒 |
| 胜利 | 大调琶音 C、E、G、C 高八度 |
| 失败 | 小调下行 E、C、A、F 低八度 |

背景音乐第一版不做，在第二阶段用 Web Audio 循环一小段 8-bit 旋律。

## 7. 代码结构建议（game.js 内）
- `Game`：状态机、主循环、输入、画面切换。
- `Input`：统一键盘和鼠标，暴露 `isDown(action)`。
- `Player`、`Enemy`（含类型）、`Boss`、`Bullet`、`PowerUp`、`Particle`：每个类有 `update(dt)` 和 `draw(ctx)`。
- `Level`：读取 `LEVELS` 数据，负责出怪和镜头滚动。
- `Audio`：封装 `beep(type, ...)` 和 `speak(text, role)`。
- `UI`：血条、分数、道具图标、字幕。
- 碰撞用圆形或矩形 AABB，不要用像素检测。
- 对象池：子弹和粒子用数组复用，避免频繁创建。

## 9. 测试清单
- Chrome 和 Safari 各通关一次，控制台没有报错。
- 窗口缩放到 400px 宽时画面不溢出，等比缩放。
- 把标签页切到后台再回来，游戏不会瞬移（delta time 要限制最大 0.05 秒）。
- 连续死亡 3 次，Boss 血量按规则下降。
- 关掉声音权限，语音失败时字幕仍然出现。
