# Zachary 大战 Deadline（Meme Shooter）

网页版横版卡关射击小游戏。主角、小兵、Boss 都用真实照片当脸，搞笑风格，轻松难度。
纯前端：**双击 `index.html` 就能玩**，不需要服务器、不需要打包。

## 怎么玩

| 动作 | 键盘 |
|---|---|
| 左右移动 | `A` / `D` 或 `←` / `→` |
| 跳跃 | `W` / `↑` / `空格`（长按跳得高，短按小跳） |
| 射击 | `J` 或 鼠标左键（按住连发） |
| 大招（需要先捡 Ctrl+Z） | `K` |
| 暂停 / 继续 | `P` 或 `Esc` |
| 静音 / 开声音 | `M` |
| 结算页 | `R` / `Enter` 再来一次，`Esc` 回标题 |

打赢第 1 关「Bug 森林」：一路打到最右边，进 Boss 房间打败 **Deadline**。
Boss 第二阶段会冲撞，看到地上的红线就**跳起来**。

## 换成你自己的脸

把三张图放进 `assets/`（文件名不要改）：

| 文件 | 尺寸 | 说明 |
|---|---|---|
| `player.png` | 150×150 | 主角头像，圆形透明底 |
| `minion.png` | 120×120 | 小兵头像，圆形透明底 |
| `boss.png` | 190×357 | Boss 全身像，透明底 |

**没有这些图也能玩**：缺图时游戏自动画占位头像（标题页左上角会提示）。放好真图后刷新页面就自动替换，不用改任何代码。

> 素材里的肖像只用于个人和朋友间娱乐，不要公开发布或商用。

## 改台词 / 改关卡

- 台词：`js/data.js` 里的 `LINES`，直接改字符串。说话人的名字和字幕颜色在同一文件的 `ROLES`。
- 关卡：`js/data.js` 里的 `LEVELS`，每个出怪点是 `{ x, t, off? }`。第 2、3 关只需要往数组里加元素。
- 数值（速度、跳高、血量、Boss 节奏）：`js/config.js` 的 `PLAYER_CFG`、`js/boss.js` 的 `BOSS_CFG`、`js/enemy.js` 的 `ENEMY_DEF`。

## 目录结构

```
meme-shooter/
  index.html          页面和 canvas
  style.css           外壳样式（居中、黑底、16:9 等比缩放）
  game.js             主循环、状态机、碰撞、画面切换
  js/
    config.js         全局常量 + 小工具函数
    data.js           LEVELS（关卡）、LINES（台词）、ROLES
    assets.js         素材加载 + 缺图时的占位图 + 灰色/白闪变体
    input.js          统一键盘和鼠标：isDown / wasPressed
    audio.js          Web Audio 合成音效 + speechSynthesis 语音
    pool.js           对象池（子弹、粒子、敌人、道具）
    particles.js      粒子（方块爆炸、彩带、飘字、圆环）
    bullet.js         子弹：笑脸 / {} / 作业纸片 / 报错弹
    enemy.js          小兵：爬行 / 跳跃 / 飞行 Bug + 道具箱
    player.js         主角
    boss.js           Boss「Deadline」三阶段
    powerup.js        5 种道具 + 掉落规则
    level.js          读取 LEVELS，出怪和触发 Boss 房间
    background.js     三层视差背景（全部 Canvas 绘制）
    ui.js             HUD、Boss 血条、字幕、横幅、暂停画面
    screens.js        标题页 / 失败页 / 通关页 + 最高分存取
  assets/             player.png / minion.png / boss.png（自己放）
  PLAN.md             最初的开发方案
```

## 调试

URL 后面加 `?debug`：左下角显示帧率和实体数量。浏览器控制台里可以用 `__game`，例如：

```js
__game.godMode = true      // 无敌
__game.player.x = 3910     // 瞬移到 Boss 房间门口（需要先开始游戏）
```

## 决定记录

方案里没写清楚的地方，我选了最简单的做法，记在这里（想改的话从这里找入口）：

1. **代码拆成多个文件。** 方案说 `game.js` 超过 800 行再拆；实际远超，所以拆成 `js/` 下十几个文件，`game.js` 只留主循环和游戏流程。用普通 `<script>` 标签而不是 ES module，因为 Chrome 在 `file://` 下不允许加载 module，会破坏「双击就能玩」。
2. **素材缺失时画占位图。** 开发时没有拿到三张照片，所以代码对缺图做了兜底（`assets.js`）。灰色滤镜 / 白闪用 canvas 合成模式做，不读像素，所以 `file://` 下不会触发跨域报错。
3. **主角受击判定是一个小圆，不是只在「脑袋中心」。** 方案写的是只取脑袋中心的小圆。但头在站立时离地约 70px，爬行 Bug 只有约 50px 高，这样地面小兵永远碰不到人。所以我把判定圆放在头和躯干之间（离脚 48px、半径 20px），仍然比头像（半径 32）小一圈，擦边不算中。
4. **出怪点 `x` 的含义：** 主角走到这个 x 时，怪从屏幕右侧外面冒出来。所以「0–1200 只有爬行 Bug」指的是主角走在这一段时刷出的怪。
5. **Boss 房间 = 关卡最后一屏（3840–4800）。** 主角走到 3900 触发，镜头锁定，不能回头。Boss 站在 4650；主角最远只能走到 Boss 前约 110px，不会走进 Boss 身体里。
6. **Boss 冲撞时身体会被压扁。** Boss 全身像有 357px 高，主角最多跳 140px，不压扁就没法「跳过」。所以冲撞时 Boss 纵向压扁到 25%（既是视觉上的「趴下滑行」，也是为了让判定可跳过）。红线预警 0.8 秒，起跳窗口约 ±0.2 秒。
7. **「主角没有血时下一个小兵必掉爱心」理解为：只剩 1 颗心时。** 触发一次后清零，直到下一次掉到 1 颗心。血满时不会随机掉爱心。
8. **死亡减 Boss 血量：** 每死一次（不管死在哪），下一次尝试 Boss 血量 −10%，最低 50%（60 → 54 → 48 → 42 → 36 → 30）。通关后清零。只存在当前页面里，刷新就重置（只有最高分会存档）。
9. **Ctrl+Z 最多存 1 个。** 已经有 1 个时再捡，+300 分。大招只清屏幕内的小兵和敌方子弹，不伤 Boss、不碰道具箱。血满时捡爱心 +200 分。
10. **道具箱必掉道具；** 小兵 15% 掉。咖啡和双发各自独立计时，重复捡刷新到 10 秒；护盾不限时。
11. **飞行 Bug 悬停高度 285–335px。** 主角只能水平射击，站着能打到摆动的最低点，起跳能打到最高点，否则永远打不到。
12. **跳跃键可变高度：** 长按跳满约 140px，提前松开会提前收力。
13. **额外加的内容：** 方案音效表之外加了几个手感音效（Boss 发弹 / 召唤 / 冲撞预警 / 撞墙 / Ctrl+Z / 爆炸等）；`LINES` 里在方案初稿之外补了小兵、阶段切换、Ctrl+Z、护盾几组台词；顶部关卡进度条；落地灰尘和枪口火花。
14. **失去焦点 / 切到后台会自动暂停。** 同时 delta time 最大限制 0.05 秒，回来后不会瞬移。
15. **结算页：** `R` 或 `Enter` 直接再来一局，`Esc` 回标题。字幕在结算页不重复显示（大字台词已经在屏幕中央）。
16. **得分：** 小兵 +100，道具箱 +50，打中 Boss 每发 +20，击败 Boss +2000。
17. **高分屏：** 逻辑分辨率固定 960×540，设备像素比 ≥1.5 时后备缓冲用 2 倍，画面更清晰。

## 已知限制

- 开发和自动化测试用的是 Chromium（含 `file://` 直接打开）。**Safari / Firefox 我没有实测**，代码里没有用到它们不支持的 API（`ctx.roundRect`、`ctx.filter` 都避开了），但请你在 Safari 上实际通关一次确认。
- 语音依赖浏览器自带的中文语音包；没有时只显示字幕（这是方案里要求的行为）。
- 第二阶段内容（第 2、3 关、手机触屏、背景音乐、选角色、在线排行榜）按方案**没有做**。
