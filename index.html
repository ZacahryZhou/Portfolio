AI agent · Web app

Kiro

An AI agent that does the admin of a tutoring business.

  • Next.js
  • React
  • TypeScript
  • Prisma
  • NextAuth
  • Docker

How every teacher write happens

  1. AI proposal
  2. teacher confirms
  3. service function
  4. data written
  • Takes attendance, reschedules classes, drafts quizzes and answers student questions. The AI only proposes changes. Nothing is written until a teacher confirms.
  • Checks every citation in an answer against the teacher's own materials with code. If the quote is not there, the agent says it could not find it.
  • Isolates data by signed-in identity: teachers see only their courses, students only their own data. Student messages and text read from photos are treated as untrusted input.

Agent system

SMAS

An Instagram content agent system.

  • Python
  • LangGraph
  • Telegram

The seven stages

  1. classify
  2. brief
  3. caption
  4. visual direction
  5. render
  6. preview
  7. human review
  • Turns a plain-language request into an Instagram draft, run from a command line, a Telegram bot or a mobile bridge.
  • Approve, skip or edit gates mean no draft is finalized without review.
