  • Next.js

github.com/ZacahryZhou/Kiro

How every teacher write happens

AI proposal→teacher confirms→service function→data written
  • Takes attendance, reschedules classes, drafts quizzes and answers student questions. The AI only proposes changes. Nothing is written until a teacher confirms.
  • Checks every citation in an answer against the teacher's own materials with code. If the quote is not there, the agent says it could not find it.
  • Isolates data by signed-in identity: teachers see only their courses, students only their own data. Student messages and text read from photos are treated as untrusted input.
